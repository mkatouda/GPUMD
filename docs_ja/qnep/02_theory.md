# 第 2 章 理論（実装されている式）

本章は、`charge_transfer` モデルが**実際に計算している式**をまとめます [DES-0005 2〜3 節、VER-0029、VER-0033]。記号は次のとおりです。

| 記号 | 意味 |
|---|---|
| h_a | 原子 a のネットワークの電荷出力（ポテンシャル）。記述子と型だけで決まる |
| φ_ab = φ_{t_a t_b}(r_ab) | 型対ごとの対称なペア関数。`r_ab ≤ rc_phi` で 0 でない。ペア関数の展開は動径基底 `φ(r) = Σ_k c_k f_k(r) fc(r)` |
| q_a | 電荷 |
| P | 分極に相当する量（e·Å） |
| Z_k | BEC。`Z[k, β, α] = ∂P_β/∂r_{k,α}`（配列の添字 `3β + α`） |
| V_a | `Σ_b φ_ab (r_a − r_b)`（最小イメージのベクトル） |
| D_a | `∂E_el/∂q_a`（長距離ソルバー Ewald/PPPM が与える） |
| s | `√ε∞`（`scale_bec` の因子） |

## 2.1 電荷：グラフ・ラプラシアン型の電荷移動

h を、電荷の代わりに**スカラーポテンシャル**として扱い、電荷を

$$q_a = \sum_{b} \phi_{ab}\,(h_a - h_b)$$

とします（b は `rc_phi` 以内、最小イメージ）。φ が対称（φ_ab = φ_ba）なので、b から a への移動量は a から b への移動量の符号反転であり、

$$\sum_a q_a = 0$$

が**どの配置でも厳密に成り立ちます**（平均の差し引きは不要。`zero_total_charge` は走りません）。電荷は h の高い側から低い側へ流れ、電気陰性度に駆動される電荷移動の形をしています。

局所性：q_a は a の近傍 b と、b の近傍にある h_b に依存するので、q_a は `rc_phi + rc_desc` 以内の原子に依存します。BEC の導出では、これを a を中心とした和に書き換えるため、二段の最小イメージ（2-hop MIC）は不要です（2.3 節）。

## 2.2 P と、なぜ厳密な勾配が存在するか

$$\mathbf P = \sum_a q_a\mathbf r_a = \sum_{a<b}\phi_{ab}\,(h_a-h_b)\,(\mathbf r_a-\mathbf r_b) = \sum_a h_a \mathbf V_a$$

右辺の各項はペアのベクトル r_ab だけに依存するので、P は**剛体並進で不変**で、周期境界でも**一価**です（r_ab は最小イメージ。φ は `rc_phi` で滑らかに 0 になる）。一方、周期系の `Σ q_a r_a`（折り畳んだ座標）は、周期イメージの取り方で値が変わる多価の量です。

従来のモデルが勾配になれなかった理由（0 章）は、平均の差し引き（S_k ≠ 0）で非局所項が入ることでした。新モデルは Σq = 0 を構成で満たすので S_k = 0 で、局所的な BEC が厳密な勾配になります（人間の決定 D1(a)）。

## 2.3 厳密な BEC：項 A + 項 B

P = Σ_a h_a V_a を r_k で微分すると

$$Z_{k,\beta\alpha} = \underbrace{\sum_a V_{a,\beta}\,\frac{\partial h_a}{\partial r_{k,\alpha}}}_{\text{項 A}} \;+\; \underbrace{\sum_a h_a\,\frac{\partial V_{a,\beta}}{\partial r_{k,\alpha}}}_{\text{項 B}}.$$

**項 A**（h の位置依存性）：a と、a の記述子カットオフ内の原子 b について、ネットワークの連鎖律で G_ab = ∂h_a/∂r_b（動径部分は `Σ_n (∂h/∂d_n) g_n'(r) û`、角度部分は `2 Σ_m (∂h/∂d_m)[g_m' û (S_m·x) + g_m S_m]`、x = r_b − r_a、S_m = Σ g_m x）を作り、外積 `V_a ⊗ G_ab` を Z_b に加え、Z_a から引きます。これは静電気力に使う既存の力カーネルと同じ構造で、重みが `V_a,β`（β = x,y,z の 3 回分）なだけです。実装は **1 回のパスで 9 成分すべてを出します**（3 回のパスと等価）。

**項 B**（φ の位置依存性）：

$$\text{項 B}_k = \sum_b M_{kb}\,(h_k - h_b),\qquad M_{kb}=\phi'(r)\,\hat{\mathbf x}\otimes\mathbf x+\phi(r)\,\mathbf 1,\quad \mathbf x=\mathbf r_k-\mathbf r_b$$

導出：∂V_a/∂r_a = Σ_b M_ab、∂V_a/∂r_b = −M_ab（M は対称）なので、Σ_a h_a ∂V_a/∂r_k = Σ_b M_kb (h_k − h_b)。自己イメージ（b = a、s ≠ 0）は h_a − h_a = 0 で消えます。

重要な点：

- **対角の q_k·1 は項 B の `φ·1` の部分に含まれます**（Σ_b φ (h_k − h_b)·1 = q_k·1）。カーネルで別に加えると二重に数えます（`find_bec_diagonal` は走りません）。
- 「T2 のみ」の簡単な形（q_k 1 + Σ_a (r_a − r_k) ⊗ ∂q_a/∂r_k）が厳密になるのは `rc_desc + rc_phi < L/2` のときだけです。**項 A + B の形は、通常のカットオフごとの箱の検査を通る任意の箱で厳密**です（VER-0029 で、`rc > L/2` でイメージを数える場合も含め確認）。
- Z は非対称です。9 成分すべてを保存し、添字は `[3β + α] = ∂P_β/∂r_α` です。
- 出力される BEC は `s × Z`（`scale_bec`）。
- ΣZ_k = 0（並進不変性）は、float64 の参照実装で 4×10⁻¹⁵ 以下で成り立ちます（6 ケース）[VER-0029]。

## 2.4 力とビリアル

エネルギー E = E_el(q(r, h), r, h)。長距離ソルバー（Ewald/PPPM）は D_a = ∂E_el/∂q_a と、q 固定のペア力を与えます。q_a が h の関数であることから、

1. **記述子の重み**：`Dt_c = ∂E/∂h_c = Σ_b φ_cb (D_c − D_b)`（`rc_phi` のループ）。導出：Σ_a D_a q_a = Σ_{非順序ペア} φ_ab (h_a − h_b)(D_a − D_b)（D 固定）。
2. **記述子の力**：`F_k −= Σ_a Dt_a ∂h_a/∂r_k`。静電気力の既存の力カーネルと同一で、重みを Dt にしたもの（従来の `D − mean(D)`、`zero_mean_D_real` の代わり）。
3. **ペア項**（φ(r_ab) の位置依存性、h と D 固定）：`g_kb = φ'(d)(h_k − h_b)(D_k − D_b)`、`F_k += g_kb v/d`（v = r_b − r_k）。g_kb = g_bk、v は反転するので作用・反作用が成り立ち、各原子は自分にだけ加えます。
4. **q 固定の明示力**（ソルバー内）：`q_k q_b K'(d)` の形。既存の Ewald/PPPM の力に含まれます。
5. **ビリアル**：`W_ab = −Σ v_a Dt_a G_ab − 0.5 Σ_{順序ペア} (g + g^K) v_a v_b/d`（記述子部分はペアの力の外積、ペア部分は順序ペアごとに 0.5）。ソルバーの k 空間ビリアルは変わりません。

従来の重み `D_c − mean(D)`（平均を引く重み）は、このモデルでは勾配になりません（VER-0033 で確認）。力・ビリアルのすべての項が a 中心の和で、二段の和は不要です。

## 2.5 電場中の仕事とエネルギー

`add_efield ... bec` は `F_α = Σ_β bec[3β+α] E_β` を加えます（`bec = s Z`）。Z[3β+α] = ∂P_β/∂r_α なので、これは `F = ∇_r (s E·P)` です。つまり、**一定電場が加える力は、エネルギー −s E·P から導かれる保守力**です。ただし `add_efield` は力だけを加え、`thermo.out` のエネルギーに −s E·P は含まれません。したがって：

- K+U は保存しません（電場が仕事をします）。
- **K + U − s E·P_direct が保存**します（VER-0034：電場なしと同じ質）。
- 閉じた経路（周期的な軌道）の電場の仕事は、旧 qNEP の BEC では経路依存（閉ループ積分 / 被積分関数のスケール 0.16〜0.50）、新モデルでは 1.4×10⁻⁵〜8.3×10⁻⁴（薄い箱）、2.2〜2.8×10⁻⁴（厚い箱）でした（04 章）。

## 2.6 限界（理論面）

- q = L h（L はラプラシアン型の演算子、h は局所）という形は、**表せる中性の電荷パターンを制限**します。実データでの BEC の精度が落ちる可能性があり（DR-005 A6）、5a の短い学習で確認しています（05 章）。
- φ の正値性は強制していません（数学的に不要）。フィッティングでは符号に注意してください。
- 電荷は目標値で学習しません。BEC・エネルギー・力・ビリアルのラベルで学習します。
- 検討した代替案（採用せず、5a が不合格のときに再検討）：ペアのネットワークによる環境依存の φ、ボンド電荷増分のみのモデル（環境依存が弱すぎる）、直接の双極子モデル（`nep_dipole`、D1 の (b)）[DES-0005 7 節]。
