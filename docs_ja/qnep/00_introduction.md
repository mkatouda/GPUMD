# 第 0 章 背景と結論

## 0.1 何が問題だったか

PTFE の qNEP（BEC 付き）モデルで交流電場の非平衡 MD（`add_efield <gm> <gid> <file> bec`、`compute_dpdt`）を行うと、ω·χ″ が 20〜500 GHz でほぼ一定になる**疑似的な散逸**が現れました。ゼロ電場でも、∫Σ BEC·v dt（P の時間積分）が結晶ですら飽和せず、⟨ΔP_z²⟩ は遅延 1/5/20/100 ps で 1.58、5.66、22.9、62.2 e²Å² と増え続けました [DR-005 Problem]。依頼元は GPUMD-polymer-apps S-005（Tier P：試作で、物理予測ではない）です。

## 0.2 原因（段階 1 の診断、VER-0028）

従来の qNEP の BEC は、カーネルの式

BEC_k = s [ qn_k·1 + 0.5 T1_k + 0.5 T2_k ]（s = √ε∞、qn = q − mean(q)）

で計算されます（T1、T2 は生の電荷 q の位置微分から作る項）。この式は並進不変（ΣZ_k = 0）ですが、**P = Σ qn r の勾配ではありません**。PTFE のオリゴマー（59 原子）とアモルファス（248 原子）で次を確認しました [VER-0028]。

- 依頼元の数値（カーネルと厳密勾配の差 RMS 0.430 / 0.188 e、フィット係数 (0.68, 0.05) / (0.493, 0.483)）を 5 % 以内で再現。
- 「(0.5, 0.5) の重みがアモルファスには合うがオリゴマーには合わない」という見かけは、**中性化後の電荷のヤコビアン**（Jn = J − S/N、非局所）を使った結果でした。生のヤコビアンを使うと、両構造とも a = b = 0.500 で一致します。
- 局所的な BEC が、並進不変な P の厳密な勾配になれるのは **S_k = ∂(Σ_a q_a)/∂r_k = 0**（総電荷が局所的に保存される）ときだけです。従来のモデルは S_k ≠ 0（RMS 0.14〜0.16 e/Å）でした。平均を引く中性化が、S_k ≠ 0 を非局所項として持ち込んでいます。

## 0.3 結論と対応（人間の決定 D1(a)、2026-11-11）

**総電荷が構成上かならず 0 になる qNEP を新設**し、BEC のカーネルを厳密な形に改めました。これは係数の調整ではなく、**モデルの変更（再学習が必要）**です。

- 新キーワード `charge_transfer <rc_phi>`（`nep.in`）。電荷を `q_a = Σ_b φ_ab (h_a − h_b)` とします（h はネットワークの電荷出力、φ は対称なペア関数）。
- BEC は P = Σ_{ペア} φ_ab (h_a − h_b) r_ab の**厳密な勾配**（`dump_xyz ... bec`、`bec.out`、`compute_dpdt`、`add_efield ... bec` が同じ配列を使う）。
- 力・ビリアルは同じエネルギーと整合（有限差分で検証）。電場中の仕事とエネルギー K+U−√ε∞ E·P の保存も確認済み。
- **既存のモデルと `nep.in` は変更なし**（ADR-0006）。キーワードの無い入力と、`charge_transfer` 行の無い `nep.txt` は従来どおり読み評価されます。

## 0.4 何を保証し、何を保証しないか

| 保証する（構成と検証） | 保証しない |
|---|---|
| 総電荷が厳密に 0（丸め誤差を除く） | 学習したモデルの**物理的な精度**（電荷は目標値では学習しない） |
| P の並進不変性、BEC = ∂P/∂r（有限差分で確認） | 実データでのモデルの**表現力**（q = L h は、h が局所だと表せる中性の電荷分布が限られる。05 章） |
| 力・ビリアル・エネルギーの整合（NVE、有限差分） | 周期系での P そのものの出力（未実装。`compute_dpdt` は dP/dt を出す） |
| 既存モデルの結果が変わらない（ビット同一、ただし既存の雑音を除く） | 疑似散逸が消えること（再学習後に依頼元が確認する。DR-005 範囲外） |

## 0.5 使い分け

| 状況 | 推奨 |
|---|---|
| 既存の qNEP モデルをそのまま使う | 変更不要。従来どおり |
| 電場中の MD で BEC を使い、エネルギーと仕事の整合や P の有界性が必要 | `charge_transfer` で**新しく学習する**（既存モデルは流用不可） |
| 電荷の目標値（`charge=` ラベルが 0 でない構造）で学習したい | 不可（入力エラー。総電荷は常に 0） |
| 分散力補正（D2/D3）と併用 | 可（`dftd3`/`dftd2` は NEP 側の別機能。`docs_ja/dftd`） |
| `gpumd_replica` で使う | モード 2（`qnep2`）のみ。ただし GPU 検証は未完（05 章） |
