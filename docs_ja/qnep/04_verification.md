## 4.2 診断（段階 1、VER-0028）

方法：生の電荷の有限差分ヤコビアン J[a,k,α] = ∂q_a/∂r_{k,α}（中心差分、gpumd の 1 ステップ実行 6N 回、`kspace pppm`、倍精度ダンプ）。生の電荷は、`zero_total_charge` を無効にした**使い捨てのビルド**（`src/` のコピー）で得ました（リポジトリのバイナリは変更なし）。

| 量 | オリゴマー 59 原子 | アモルファス 248 原子 | 依頼元 |
|---|---|---|---|
| RMS(GPUMD − 厳密な勾配) [e] | 0.4301 | 0.1877 | 0.430 / 0.188 |
| フィット係数 (a, b)（BEC − q·1 = a T1 + b T2） | 0.682, 0.049 | 0.493, 0.483 | 同左 |
| RMS(BEC) [e] | 0.391 | 0.442 | 同左 |

- 仮説 H0（現在のカーネルの式、生の J）：GPUMD との差 RMS 0.0003〜0.0005 e（δ = 0.02 Å）。差は δ に反比例して減る（FD の float 雑音）。ゲート 1×10⁻³ を満たす。
- 仮説 H1（H0 + 中性化の項）：差 0.431 e（オリゴマー）、0.029 e（アモルファス）。**棄却**（BEC に中性化の項はない）。
- 生の J でのフィット：両構造とも a = b = 0.500。
- 中性化の効果が大きいのはオリゴマー（33 Å の分子が 40 Å の箱）で、非局所項 `−(r_c − r_k) × S_k` が RMS 0.43 e、アモルファスでは 0.03 e でした。S_k の RMS は 0.140 / 0.156 e/Å。
- 候補 C1〜C4（厳密な勾配の候補）はすべて、カーネルから 0.12〜0.9 e 離れ、並進不変性（ΣZ_k = 0）か局所性のどれかを満たしませんでした。**局所的な BEC が並進不変な P の厳密な勾配になるのは S_k = 0 のときだけ**であり、モデルの変更が必要、が結論です（人間の決定 D1(a)）。

## 4.4 GPU の電荷と BEC（段階 2b、VER-0032）

基準：gpumd のモデルから作った単一価の P の FD（`scripts/ct_bec_fd.py`、δ = 0.02 Å）。「全原子」は全原子を順に動かした場合。

| 構造（rc_radial/rc_phi、経路） | RMS(BEC/√ε∞ − Z_FD) | RMS Z | Σq（float ダンプ） |
|---|---|---|---|
| n8、L13、4/4、大箱 | 3.1×10⁻⁶ | 8.3×10⁻³ | 0 |
| n45、L14、4/4、大箱 | 7.2×10⁻⁵ | 0.143 | −1.7×10⁻⁸ |
| n59、L16、4/4、大箱 | 8.0×10⁻⁵ | 0.128 | 4.9×10⁻⁹ |
| n12、L7.5、4/4、小箱 | 1.8×10⁻⁴（δ 0.01 では 4.6×10⁻⁵） | 0.34 | −3.0×10⁻⁷ |
| n10、L6、4/4、小箱 | 1.2×10⁻⁴ | 0.29 | 3.2×10⁻⁷ |
| n8、L13、5.5/4、小箱（強制） | 1.2×10⁻⁵ | 0.040 | 0 |
| 広い箱 n59、L18、4/4 | 9.2×10⁻⁵ | 0.145 | 2.4×10⁻⁸ |

- ゲート：Σq ≤ 1×10⁻⁶ e、gpumd と host の q の差 ≤ 3×10⁻⁷ e、RMS(BEC − FD) ≤ 1×10⁻³ e（A1）。全行で合格（最大 1.8×10⁻⁴）。
- 誤差は δ² に比例（n12：δ 0.02 で 1.8×10⁻⁴、0.01 で 4.6×10⁻⁵）で、FD の打ち切り誤差です（float の雑音ではない）。
- 最初の生成器は重みが大きく、薄い箱で |q| が最大 5.7 e となり、float の Σq が 2×10⁻⁶ に達しました。**ゲートを緩めずにモデルのスケールを下げて**対応しています（φ の係数の最大 0.3、w1 の標準偏差 1.5）。
- 試験が空虚でないこと：RMS Z > 0.02 を要求し、BEC がほぼ 0 でも通らないようにしています。ほかに、原子の入れ替えに対する q・BEC の不変性（≤ 1×10⁻⁵）、2 回の静的実行で q が同一であること。
