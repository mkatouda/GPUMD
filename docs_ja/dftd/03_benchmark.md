# 第3章 計算コストとベンチマーク

本章では、`dftd3` と `dftd2` が 1 ステップあたり何 ms を追加で必要とするかを、測定記録（`specs/verification/`）に基づいて示します。数値はすべて `[VER-xxxx 節]` の形で出典を付けています。「導出値」は、出典の数値から本章の作成者が計算した値です。出典に無い条件は「未測定」と書きます。

最初に、読み方の注意を三つ挙げます。

- **測定は 1 台の GPU（RTX A6000）、1 つのビルドでの値です。** 他の GPU や HIP では測っていません（3.7 節）。
- **「slope（傾き）」と「nsys 合計」は別の量です。** 受入基準（DR-001 AC-4）は slope で定義されています。nsys 合計は D3 のカーネル時間の和で、slope より 0.1〜0.35 ms 小さくなります（3.1 節）。本章の表では両者を別の列に置き、混ぜません。
- **古い測定値は、最適化前の値として明示した場合にだけ載せます。** 3.2〜3.5 節の D3 の値は、最終コードに対する VER-0018 の測定です。D2 と現行 D3 の比は VER-0021 の測定です。

### 3.1.2 slope 法の定義

1 ステップあたりの時間を、100 ステップと 500 ステップの 2 本の実行の `Time used` から

> 時間/ステップ = (t500 − t100) / 400

で求めます。起動時間（約 1.3 秒）が差し引かれます。補正の追加時間（extra）は、補正ありの slope から補正なしの slope を引いた値です [VER-0001 Timing, VER-0018 S2]。

測定ごとの手順の違いは次のとおりです。

| 測定 | 手順 | 出典 |
|---|---|---|
| VER-0018（D3 最新） | master 基準と最適化版のバイナリを交互に実行、3 回繰り返し、**中央値** | VER-0018 S2 |
| VER-0021（D2 対 現行 D3） | 1 回の繰り返しの中で 4 変種（補正なし、D3、D2 rc 12、D2 rc 30）を順に実行し、同じ繰り返しの補正なしとの差を extra とする。3 回の中央値と [最小, 最大] | VER-0021 |
| VER-0010（D2 最終） | slope、補正の有無の差 | VER-0010 B |
| VER-0011 B（古い D3 の slope） | 各点 2 回の最小値（3 回の中央値ではない） | VER-0011 B |
| VER-0006/0008（D2 旧） | (T(n2) − T(n1))/(n2 − n1)、n1 = N_steps/5、2 回の最小値。高価なケースはステップ数を減らして長い方の実行を約 20 秒にする | VER-0006 s5, VER-0008 s6 |

### 3.1.3 nsys 合計

D3 のカーネル（近傍リスト／セルリスト構築、CN、力、extra、必要に応じて cub scan）の 1 ステップ分の継続時間の和です。1 回の実行で 100 ステップの中央値（最初の 5 ステップは除外）をとり、さらに交互実行 3 回の中央値をとります [VER-0004 s3, VER-0012 Method, VER-0018 S2]。**AC-4 の定義ではありません。** slope の extra には、D3 カーネル以外のコスト（ホスト側、起動、NEP の配列への加算）が含まれるため、nsys 合計との差は約 0.1〜0.35 ms です [VER-0018 Not verified]。

D2 のカーネル単体の時間（最適化の履歴、3.6.2 節）は、nsys の `cuda_gpu_kern_sum` で `dftd2_pair_kernel` の中央値を取ったものです [VER-0008 ヘッダ, VER-0009 s3]。

### 3.3.3 小箱経路と大箱経路

- **小箱経路**は、近傍リストを明示的に作ります。リスト構築が全原子対と全イメージ候補を走査するため、コストは概ね N² で増えます [VER-0012 (a), VER-0018]。最適化版の実測は、N = 81/648/2,187/8,748 で 0.15/0.46/0.75/8.3 ms です。
- **大箱経路**はセルリスト（セル幅は約 rc/2）を使い、N に近い増え方をします。実測は N = 5,184/41,472 で 0.85/6.2 ms です [VER-0018, `dftd3.rst`]。
- **水 8,748（小箱経路）の場合**：厚み 27.9 Å の方向があるため 12 Å では小箱経路になります。D3 の追加時間は 8.274 ms で、同じ原子数に近い水 5,184（大箱）の 0.846 ms の約 10 倍です（導出値）。近傍リスト構築のカーネルが N = 8,748 で 7.747 ms（VER-0012 の測定）、D3 合計の 94 % を占めます [VER-0012, VER-0013]。このような**厚みの小さい細長い系で原子数が数千を超えるときは、小箱経路が支配的になる**ことに注意してください。小箱経路は rc 12 Å でも箱の厚みが 30 Å 以下で選ばれます。
- **小箱経路のメモリ**：近傍リストは原子あたり 10,000 個（`MN = 10000`）を確保します（原子あたり 320 KB、N = 34,992 で約 11 GB）。あふれは検査されていません。到達する rc は水で約 28.8 Å、fcc Cu で約 30.3 Å、ダイヤモンド C で約 23.8 Å です（測定した個数からの連続体近似）。実測のリスト長は rc 12 Å で平均 725／最大 740（水）、rc 20 Å で 3,389／3,412 です [VER-0012 (c)]。`dftd3.rst` は「水で rc < 28 Å」と記しています。
- **大箱経路の CN リスト**：バッファは N × num_sub × 容量 × 4 B で、256 MB を超えると使われなくなります（標準密度で約 4.7×10⁵ 原子以上）[VER-0015]。

## 3.4 D2 のコスト

**最適化前（参考、VER-0005 s3.5）**：水 648、NVE 1,000 ステップ、3 回の最小値、NEP89 のみ 1.555 ms/ステップ、実行時間の差から。D2 extra は rc 12/16/20/25/30/40 Å で 3.15/8.10/39.0/46.0/55.4/131.3 ms、近傍数は 723/1,714/3,351/6,542/11,311/26,801 でした。rc 16 → 20 Å の 4.8 倍（近傍数は 1.95 倍）という飛びは、セル数が n = floor(2 × 幅/rc) で量子化されることが原因で、Phase 6 stage 2 の (i) で解消されました [DES-0002 Phase 6 stage 1 (c), VER-0008 s2]。この表の値は現在のコードには当てはまりません。

最適化後の rc 40 Å と、rc 16・20・25 Å の最終コードでの全ステップ値（水 648、5,184 以外の系）は未測定です。

### 3.4.3 D2 の N 依存

VER-0021 の rc 30 Å では、D2 extra は N = 81/648/5,184/41,472 で 0.950/1.865/9.894/70.787 ms です。N が 8 倍になるごとの増え方は、81 → 648 が 2.0 倍、648 → 5,184 が 5.3 倍、5,184 → 41,472 が 7.2 倍（導出値）で、大きい N では N に比例する挙動に近づきます。小さい N では GPU が埋まらず、固定コストが支配します。rc 12 Å でも同様です（0.442/0.207/1.006/7.023 ms。N = 81 はノイズ水準）。rc 30 Å で N ≥ 5,184 の費用は原子対の数で決まり、「この方式では減らせない」とされています [VER-0010 B]。原子対の数は rc 30 Å で rc 12 Å の約 14 倍です。

VER-0010 の最終測定でも同じ傾向が出ています（D2 rc 12：0.34/0.19/1.12/7.06 ms、rc 30：0.90/1.81/10.01/68.59 ms）。ただし VER-0010 の D3 参照は Phase 3/4 時点のものです（3.6.2 節）。

## 3.7 未達の点と限界

**未達の点**

- **水 41,472 の D3（slope 6.19 ms 対 目標 6.0 ms）**：AC-4 の定義では未達で、目標は人間の判断で取り下げられました（3.2 節）。nsys 合計では 5.875 ms です。
- **AC-7（D2 ≤ 0.5 × D3）**：VER-0021 の 10 点のうち達成は水 648・rc 12 Å の 1 点（D2 extra はノイズ水準近く）だけです。既定の rc 30 Å では全点で未達です（D2/D3 = 3.4〜17.8）。参考値の未達として人間が承認済みです（3.4.1 節）。
- **D3 の小箱経路が大きくなる場合**：水 8,748 は 8.27 ms で、NEP 単独の約 4 倍です（3.3.3 節、3.5.1 節）。厚みの小さい大きな系では、小箱経路の O(N²) 近傍リスト構築が支配的です。

**限界と未測定の事項**

- 測定は RTX A6000（sm_86）1 台、CUDA 12.3 のみです。**HIP（AMD/ROCm）ビルドは未検証です。** 他の GPU、他の CUDA バージョンも未測定です。
- 時間はいずれも 3 回の中央値で、ばらつきは 0.03〜0.2 ms 程度です。小さい extra の比較はノイズ水準になります。
- VER-0018 の slope 表は最終コミット `0c353281` では再測定していません（nsys のみ再確認、3.2 節）。
- D2 の最適化後の全ステップ時間は、rc 12 と 30 Å（VER-0010、VER-0021）と、水 648・5,184 の rc 16/20/25 Å（VER-0021）だけです。それ以外の rc（40 Å を含む）や他の系は未測定です。
- D3 の rc 20 Å を超える範囲、最適化版の rc 25/CN 15、他の密度は未測定です。急増の原因（水 5,184 の 16 → 20 Å）は調べていません。
- D2 の NEP 比は N = 2,187/8,748 で未測定です。
- 複数 GPU、複数ノード、MPI での挙動は対象外で、測っていません。
- VER-0010 の D2 結果の D3 参照は Phase 3/4 時点のコードで、現行コードでの比は VER-0021 にだけあります。2 つのセッションの値を混ぜた比は、本章では使いません。
