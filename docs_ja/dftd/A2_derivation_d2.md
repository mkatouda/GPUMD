# 付録 A2 DFT-D2 の力・ビリアルの導出（QE 型テーブル、単純打ち切り、補償付き累算を含む）

本付録は、[第2章](02_theory.md) 2.6 節の D2 の式を導きます。導出した式は `scripts/check_d2_derivation.py` と `scripts/check_d2_tail.py`（CPU、NumPy、倍精度）で確認しました（A2.7 節）。A2.8〜A2.9 節は DR-004 で追加した QE 型テーブル、単純打ち切り、補償付き累算で、`scripts/check_d2_qe_plain.py` で確認しました（A2.9.4 節）。A2.1〜A2.7 節は Grimme 2006 の表とシフト付き力（既定）についてで、DR-004 の R3 で累算の方法が変わった後も式は同じです。

## A2.1 エネルギー

Grimme (2006) の D2 は、ペアごとの項

$$
\phi(r) = -\,s_6\,C_6^{ij}\,\frac{f(r)}{r^6},\qquad f(r) = \frac{1}{1+e(r)},\quad e(r) = \exp\!\left[-d\left(\frac{r}{R_0^{ij}} - 1\right)\right],\quad d = 20
$$

を $r<r_c$ のすべてのペアと周期イメージについて足します。$C_6^{ij} = \sqrt{C_6^iC_6^j}$（元素ごとの値の幾何平均）、$R_0^{ij} = R_0^i + R_0^j$ です [D2:22-23]。以下、$A \equiv s_6C_6^{ij}$ と書きます（コードの `par.x` = `s6c6`、`par.y` = $R_0$ [D2:659-662]）。

## A2.2 ダンピング関数の微分

$e'(r) = -(d/R_0)\,e$ なので

$$
f'(r) = -\frac{e'}{(1+e)^2} = \frac{d}{R_0}\,e\,f^2
$$

です（コード `dfdr = (D/R0) * e * f * f` [D2:85, 446]）。$\phi = -A f r^{-6}$ を微分すると

$$
\phi'(r) = -A\left[\frac{f'(r)}{r^6} - \frac{6\,f(r)}{r^7}\right]
$$

です [D2:87, 448]。第 1 項は、$f$ が $r$ とともに増える（短距離で引力が切られる）ことによる、斥力方向（$\phi'<0$）の寄与、第 2 項は $r^{-6}$ 項そのものの微分です。

スクリプトで 100 組のランダムな $(Z_i, Z_j, r)$ について中心差分と比べ、最大相対誤差は $1.2\times10^{-9}$ でした。

## A2.3 シフト付き力の打ち切り

エネルギーと力の両方が $r_c$ で 0 になるように、$r<r_c$ で

$$
\phi_{\mathrm{sf}}(r) = \phi(r) - \phi(r_c) - \phi'(r_c)\,(r - r_c)
$$

とし、$r\ge r_c$ では 0 とします [D2:25, 449]。これを $r$ で微分すると

$$
\phi_{\mathrm{sf}}'(r) = \phi'(r) - \phi'(r_c)
$$

です [D2:450]。$\phi_{\mathrm{sf}}(r_c) = 0$、$\phi_{\mathrm{sf}}'(r_c) = 0$ なので、エネルギーも力もカットオフで連続です（スクリプトで確認、値は $r = r_c$ で厳密に 0）。

**コードの実装**：`phi_sf = phi - par.z - par.w * (r - rc)`（`par.z` = $\phi(r_c)$、`par.w` = $\phi'(r_c)$、ホスト側で倍精度に計算し `float` で保持 [D2:660-665]）、`dphi_sf = dphi - par.w`。カットオフ $r_c$ は最初に `float` に丸めて以降すべてに同じ値を使います [D2:624]。

## A2.4 力

エネルギーは $E = \sum_{i<j}\phi_{\mathrm{sf}}(r_{ij})$ です。$\partial r_{ij}/\partial\mathbf{r}_i = -\mathbf{r}_{ij}/r_{ij}$（$\mathbf{r}_{ij} = \mathbf{r}_j - \mathbf{r}_i$）なので

$$
\mathbf{F}_i = -\frac{\partial E}{\partial \mathbf{r}_i} = \sum_{j}\phi_{\mathrm{sf}}'(r_{ij})\,\frac{\mathbf{r}_{ij}}{r_{ij}} = \sum_j\big[\phi'(r_{ij}) - \phi'(r_c)\big]\frac{\mathbf{r}_{ij}}{r_{ij}}
$$

です（$i$ を含む全ペア、順序付き）。コードは `g = dphi_sf * rinv; fp = g * dx`（`dx` $= \mathbf{r}_{ij}$ の成分）で $\mathbf{F}_i$ に加えます [D2:452-458]。符号：$\phi_{\mathrm{sf}}'>0$ なら $\mathbf{F}_i$ は $j$ の向きで、引力です。

原子エネルギーは各ペアの半分ずつ `e_i += 0.5 * phi_sf` [D2:451] で、全原子の和が $E$ です。

## A2.5 ビリアル

A1.4 節と同じ議論により（ペアが $r$ だけを通じて変形に依存する）、ペアのビリアルは $-\mathbf{r}_{ij}\otimes\mathbf{F}_i^{\mathrm{pair}}$ です。コードは順序付きペアごとに半分 `v_ab -= 0.5 * d_a * fp_b` を加えるので、ペア $(i,j)$ と $(j,i)$ の合計がペアのビリアルに等しくなります [D2:459-467]。

$$
W_{ab} = -\frac{\partial E}{\partial\varepsilon_{ab}} = -\sum_{i<j}\phi_{\mathrm{sf}}'(r_{ij})\,\frac{r_{ij,a}\,r_{ij,b}}{r_{ij}} = \sum_i x_{ia}F_{ib}
$$

（導出は A1.4 節と同じです。ペアの寄与は $-r_{ij,a}F^{\mathrm{pair}}_{i,b}$ で、中心力なので対称テンソルです。）

## A2.6 打ち切りの連続体近似（$7\pi\rho C/(3r_c^3)$）

$r$ が大きい領域では $f\to1$ なので $\phi\approx -c/r^6$（$c = s_6C_6$）です。数密度 $\rho$ の一様な系で、1 原子あたり、打ち切りなしの和（$r_c$ より先まで足す）と、シフト付き力の和との差は

$$
\Delta E = \frac{\rho}{2}\left[\int_0^{r_c}4\pi r^2\big(-\phi(r_c) - \phi'(r_c)(r - r_c)\big)\,dr \;-\; \int_{r_c}^{\infty}4\pi r^2\,\phi(r)\,dr\right]
$$

です。第 1 項は、シフトによる増分で、$\phi(r_c) = -c/r_c^6$、$\phi'(r_c) = 6c/r_c^7$、$\int_0^{r_c}r^2(r-r_c)dr = -r_c^4/12$ から $\tfrac{\rho}{2}\cdot4\pi\left[\frac{c}{3r_c^3} + \frac{c}{2r_c^3}\right]\cdot$ すなわち $\frac{5\pi\rho c}{3r_c^3}$ です。第 2 項（打ち切りなしの尾の符号を反転）は $\frac{\rho}{2}\cdot\frac{4\pi c}{3r_c^3} = \frac{2\pi\rho c}{3r_c^3}$ です。合計

$$
\Delta E = \frac{5\pi\rho c}{3r_c^3} + \frac{2\pi\rho c}{3r_c^3} = \frac{7\pi\rho\,c}{3\,r_c^3}
$$

で、DOC2（`dftd2.rst`）の式と一致します。$c$ には $\langle s_6C_6\rangle$（密度で重み付けした平均）を使います。`scripts/check_d2_tail.py` で、Gauss-Legendre 求積により、第 1 項が $5\pi\rho c/(3r_c^3)$ と相対誤差 $10^{-12}$ 未満で一致し、合計が $7\pi\rho c/(3r_c^3)$ と相対 $9\times10^{-16}$ で一致することを確認しました。

この見積もりは $f\to1$（長距離）、一様密度の極限です。短距離のダンピングと構造の不均一性は考慮していません。圧力のずれ $\Delta P = \rho\Delta E$ は導出していません（DOC2 の記述で、VER-0005 の測定が支持するとされています）。

## A2.8 QE 型の D2（`table qe`）と単純打ち切り（`trunc plain`）（DR-004）

### A2.8.1 定義

`table qe` は Quantum ESPRESSO 7.2（タグ `qe-7.2`、コミット `b4c5e8de`）の `dftd3_version = 2` と同じパラメータです。ソース（`dft-d3/core.f90` の `setfuncpar`、`pbcedisp`）を読んで確認した定義は

$$
E = -s_6\sum_{i<j,\ \text{全イメージ},\ r\le r_c} C_6^{ij}\,\frac{f(r)}{r^6},\qquad
f(r) = \frac{1}{1 + \exp\!\big[-20\,\big(r/(1.1\,r_{0}^{ij}) - 1\big)\big]}
$$

で、A2.1 節の式と**形は同じ**（$d = 20$）です。違いはパラメータの出典だけです [VER-0025 2 節]。

- $C_6^{ij}$：D3 の参照 C6 のうち、**両原子の最初の参照点**（`c6ab(Zi, Zj, 1, 1, 1)`）。配位数に依存しない固定のペア値です（Grimme 2006 の $\sqrt{C_6^iC_6^j}$ ではない）。H（最初の参照点の CN は 0.9118）と Ce（2.7991）では、自由原子の C6 ではありません [VER-0025 3 節]。
- $R_0^{ij} = \mathrm{rs6}\times r_0^{ij}$、rs6 = 1.1、$r_0^{ij}$ は D3 の `r0ab`（Å。QE は 10 進の Å 値を持ち、autoang で bohr に換算）。
- 減衰の傾きは 20（`alp`）、$s_6$ は汎関数ごと（PBE は 0.75）ですが、GPUMD ではユーザーが指定します。s18 = 0（C8 項なし）、三体項なし [VER-0025 2 節]。
- カットオフは QE では sqrt(9000) bohr（= 50.2 Å）の**ハードカットオフ**（$r^2 \le r_{thr}$ のペアを含み、シフトなし）。$i = j$（同じ原子の別イメージ）は、$r^2 \le r_{thr}$ の $\tau \ne 0$ のイメージを係数 1/2 で数えます。GPUMD では `rc` をユーザーが明示します（ADR-0004 項目 6）。
- 例：C-C、C-F、F-F の最初の点の C6 は 49.113、20.2827、9.6916 $E_h a_0^6$、`r0ab` は 2.9103、2.4770、2.2996 Å（$R_0$ は 3.20133、2.72470、2.52956 Å）。依頼元の表と一致します [VER-0025 4 節]。
- 単位：C6（$E_h a_0^6$）に、QE 7.2 の CODATA 2018 の定数（$E_h = 27.211386245988$ eV、$a_0 = 0.529177210903$ Å）から求めた $E_ha_0^6 = 0.597526904282$ eV Å$^6$ を掛けます。GPUMD の float の `HartreeBohr6` は相対 +8.74×10⁻⁷ ずれる（系統的な誤差になる）ので使いません [VER-0025 5 節]。

### A2.8.2 単純打ち切りのエネルギーと力の段差

`trunc plain` は A2.3 節の $\phi(r_c) = \phi'(r_c) = 0$ とする代わりに、$\phi_{\mathrm{sf}} \to \phi$（シフトなし）とします。

$$
\phi_{\mathrm{plain}}(r) = \phi(r)\ (r < r_c),\qquad 0\ (r \ge r_c)
$$

力 $\phi'(r)\,\mathbf{r}_{ij}/r$ も同様です。ペアが $r_c$ を横切るとき、エネルギーは $|\phi(r_c)|$ だけ、力の大きさは $|\phi'(r_c)|$ だけ不連続に跳びます。$r_c = 12$ Å では $f(r_c) \approx 1$ なので

$$
\phi(r_c) \approx -\frac{s_6C_6}{r_c^6},\qquad \phi'(r_c) \approx \frac{6\,s_6C_6}{r_c^7} = \frac{6\,|\phi(r_c)|}{r_c}
$$

です。数値（C-C、$s_6 = 0.75$、$C_6 = 49.113\,E_ha_0^6$ = 29.346 eV Å$^6$、$r_c = 12$ Å）：

- $|\phi(r_c)| = 0.75 \times 49.113 \times 0.597527 / 12^6 = 7.37\times10^{-6}$ eV（約 7.4×10⁻⁶ eV。VER-0026 の 7.4×10⁻⁶ eV と一致）。
- 力の段差 $6|\phi(r_c)|/r_c = 3.69\times10^{-6}$ eV/Å（約 **3.7×10⁻⁶ eV/Å**。**3.7×10⁻⁵ ではない**。$7.4\times10^{-6} \times 6/12 = 3.7\times10^{-6}$）。

これらは 1 回の横切りあたりの値です。系の全エネルギーに現れる段差は、横切りの回数に比例し、平衡では出入りが相殺するので系統的なドリフトを想定しませんが、短い NVE（PTFE 180 原子、3 シード、20 ps）ではドリフトは見えませんでした（06 章 6.11.3 節、証明ではありません）。

### A2.8.3 `trunc sf` との関係と、境界の規約

`trunc sf` は A2.3 節のシフトを、`table qe` でも同じ式で適用します。`trunc plain` の判定は $r < r_c$（ちょうど $r_c$ のペアは除外）、QE は $r^2 > r_{thr}$ のみ除外します（ちょうど境界のペアだけが異なり、無視できる。06 章 6.11.2 節）。

## A2.9 補償付き float 累算（DR-004 R3、ADR-0005）

### A2.9.1 何を変えたか

D2 のペアカーネルは、原子ごとに 13 個の和（エネルギー 1、力 3、ビリアル 9）を作ります。R3 の前はこれを double で累算していましたが、FP64 が FP32 の 1/64 の GA102 では、これがカーネル時間を支配していました（VER-0026 4 節、float の試作でカーネル時間が −83 %）。R3 では、ペアの項は float で計算し、各スレッドの 13 個の和を、**TwoSum で補償した float の和**（`CompensatedSum`）にして、**4 セルごと**（`FLUSH_CELLS = 4`）に double の累算へ足します。スレッド内の部分和の縮約と書き出しは double、atomic なしで、順序は固定です [ADR-0005, VER-0026 5 節, `src/force/dftd2.cu`]。

### A2.9.2 TwoSum の仕組み

float の和 `t = s + x` の丸め誤差は、`bb = t - s`、`err += (s - (t - bb)) + (x - bb)` で**誤差なしに**（浮動小数点の範囲内で）求まります（TwoSum）。誤差項 `err` を別に足し上げ、最後に `s + err` を double で返します。通常の float の和は 1 項ごとに最大 $\epsilon_f/2$（$\epsilon_f = 1.19\times10^{-7}$）の相対誤差を積み上げます（項数 $n$ で最悪 $n\epsilon_f$ 程度、ランダムなら $\sqrt n\,\epsilon_f$ 程度）。一般に、補償付きの和（Neumaier 型）は、誤差が項数にほとんど依らず、和全体で float の丸め 1 回分（項の絶対値の和に対する相対で $\sim\epsilon_f$）程度になることが知られています（これは数値解析の一般的な性質で、本記録の測定ではありません。次の A2.9.4 節のエミュレーションで確認）。TwoSum はコンパイラが再結合してはならず（fast-math なし）、項はあらかじめ float に丸めた値で渡します。積は `__fmul_rn` で丸め、FMA への縮約を避けます [`dftd2.cu` のコメント, VER-0026 5 節]。

**残る誤差**：和への各項自身の float の丸め（ペアごとの $\phi'$ や $\mathbf{r}$ の計算で生じる、項ごとの誤差）は、補償付きの和でも消えません。したがって精度は「累算の誤差」と「項の誤差」に分かれ、前者を TwoSum で小さくしても、後者は旧カーネルにもあります。実測（VER-0026 5 節）：PTFE 40,500 で旧カーネルの力の誤差が AC-1 の上限の 33.0 % で、これは累算ではなくペアごとの float 演算が決めている値です（N とともに余裕が縮み、R3 より前から存在します）。

### A2.9.3 正味の力とフラッシュの間隔

力の和は、全原子で足すとほぼ 0 になる（正味の力）はずで、補償のない累算では、項が相殺する分だけ相対誤差が目立ちます。VER-0026 は、正味の力 $|\sum\mathbf{F}|/\max|\mathbf{F}|$（試験の上限 1×10⁻¹²）で、フラッシュの間隔を選びました（rc = 30 Å）：

| 方式 | $\|\sum\mathbf{F}\|/\max\|\mathbf{F}\|$ | 時間（記録の ms） |
|---|---|---|
| 旧カーネル（double 累算） | 1.5×10⁻¹⁴ | |
| TwoSum、フラッシュなし（A3b） | **3.7×10⁻¹²（上限超過）** | 1.36 |
| 毎セルでフラッシュ | 1.6×10⁻¹⁴ | 1.94 |
| **4 セルごと（採用）** | **7.6×10⁻¹⁴** | **1.41** |
| 8 セルごと | 1.3×10⁻¹³ | 1.38 |

[VER-0026 5 節。時間の測定量（カーネルか extra か）は記録に明記が無い。4 セルの選定理由も記録に明記が無い。導出値として、4 セルの正味の力は旧カーネルの約 5.1 倍、毎セルのフラッシュに対する時間は約 0.73 倍]。フラッシュなしの TwoSum がなぜ上限を超えるかの機構は調べていません。
