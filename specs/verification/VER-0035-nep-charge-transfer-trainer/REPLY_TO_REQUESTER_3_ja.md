## 1. 「ビット同一」の対象と、訂正
- GPUMD 側で測ったのは、**静的計算（`time_step 0`）、`kspace ewald` と `pppm`、水 63 原子と BaTiO3 40 原子（どちらも small-box 経路）の qnep mode 1/2**です。電荷・力・エネルギーは、旧と新で一致し、旧同士も一致しました。応力と BEC には、float の atomicAdd の順序ノイズがありました。
- したがって、README の「旧モデルの静的計算は、電荷・力・エネルギーがビット同一」は、**この小さい系の範囲にだけ**成り立つ記述です。**大きい系や別経路には成り立つとは言えません。訂正します**（`bec_rev0` ディレクトリに注記ファイルを足しました。バイナリは変えていません）。
- ADR-0006 が求めているのは、「旧モデルが同じコード経路・同じ算術を通ること」です。これは、新旧の `nep_charge.o` の SASS 比較（既存カーネル 20/22 が同一、残る 2 つは `ParaMB` が大きくなったことによる定数オフセットだけ）で確認しています。ビット同一の再現は、大きい系では、旧バイナリ同士でも成り立ちません。ご報告の「旧 対 旧」の差（ΔE 3.5e-5 eV、max|Δq| 9e-7、max|ΔF| 9e-6）が、その実測です。
- ご報告の「旧 対 新」の差は、「旧 対 旧」と同程度なので、新旧の算術の差ではなく、旧バイナリが持つ run 間のゆらぎの範囲と判断します。
- ゆらぎの原因の見立て（未検証）: `src/force/neighbor.cu` の large-box のセルリストは、セルへの原子の格納順が `atomicAdd` 依存で、run ごとに近傍の並び順が変わりうる（行 80）。float の足し算の順序が変わり、電荷に 1e-6 程度の差が出る。オリゴマー（40 Å、large-box 経路）が該当しそうです。アモルファス（15.9 Å）は、`thickness <= 2.5 (rc+1)` なので small-box 経路のはずで、この説明では足りません。`pppm` の電荷拡散の atomicAdd も寄与しうる。切り分けは、`kspace` なしの静的計算で、旧バイナリ同士を比べると分かります。
- 位置の差 1.3e-8: `time_step 1e-6`、`run 1` で、もし `run.in` に `velocity`（seed なし）があれば、初期速度が時計で初期化され、位置が v·dt ≈ 1e-8 だけ run ごとに違います。`time_step 0` で、`velocity` なしなら、位置は一致するはずです。ΔE 3.5e-5 は、この位置の差では説明できません。

## 2. `nep` 対 `gpumd` の差が A4 の値を超える件
- GPUMD 側の A4（BEC 5e-6、力 1e-5、エネルギー 1e-5）は、**合成の小さい系（8〜59 原子）と合成モデルで決めたゲート**です。実データ、12〜768 原子、三斜晶、float32 の大きい系には、そのまま転用できません。ご報告の超過（BEC 最大 1.4e-5、力 最大 5.5e-5）は、A4 の不合格を意味しないと考えます。
- 見立て（未検証）: 差は、float32 の足し算順序のゆらぎで、原子数と力の大きさに比例して増えます。上の 1 の旧バイナリのゆらぎ（248 原子で max|ΔF| 9e-6、max|ΔBEC| 1e-6）と、同じ桁（N768 の 5.5e-5 は、N と |F| の大きさの違いで説明できる範囲）です。
- 切り分けの提案: `charge_transfer` のモデルで、`gpumd` を**同じ構造に 2 回**走らせた差（gpumd 側の床）を測り、`nep` 対 `gpumd` の差と比べてください。後者が前者の 2〜3 倍以内なら、ゆらぎで説明できます。超えるなら、算術の差（`kspace ewald` のパラメータ、トレーナー側の Ewald の設定など）が残ります。必要なら、GPUMD 側でも、再学習の後に、同じ測定をします。
- (a) `kspace`: GPUMD 側の A4 は、`kspace ewald` と同じ設定で比べて一致しました。トレーナーの静電気項が Ewald であることは、`nep` のコードで確認しています（pppm との比較は未実施）。(b) `scale_bec`: `dump_xyz bec` と `nep` の予測のどちらも、`sqrt(eps_inf)` の倍率を含んだ値で、A4 の比較では一致しています。

## 3. 参考: 5a の結果と、C の対角 BEC のずれ
