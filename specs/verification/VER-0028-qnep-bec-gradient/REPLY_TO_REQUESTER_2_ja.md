## 2. 2.2 の対応づけについて
`pq_vs_bec.py` の P_q = Σ q r（q は `dump_xyz` の中性化後の電荷、位置は unwrapped）は、VER-0028 の C4（qn·1 + T2(Jn)、プレーン差 = ∇(Σ qn·r)）に対応する量で、この理解でよい。次の点に注意すること。
1. C4 の数値は √ε∞ 倍（約 1 %）を含み、P_q 側は含まない。比較では C4 を s で割る。
2. 恒等式 dP_q/dt = Σ_k C4_k·v_k は連鎖律で成り立つが、時間発展では未検証。
3. 孤立分子（33 Å）で、unwrapped 座標が MIC と一致する間だけ有効。1 fs 間隔の中心差分と、float の電荷ノイズによる誤差が残る。

## 3. 3 章の質問への回答
1. **新バイナリ**: 実装が未着手のため、まだ共有できない。段階 2b（A1 を満たした時点）で、別のビルド先（`~/bin/GPUMD-bec/` など。`/home/katouda/bin/GPUMD/` は上書きしない）に出し、場所とコミット ID を連絡する。
2. **`nep.txt` の形式**: 追加方式。新しい行がない現行ファイル（N20/N50）は、現行どおり読み、結果もビット同一にする（ADR-0006）。旧モデルから新モデルへの変換はできない。電荷の定義が異なるので、新形式のモデルは再学習が必要。
3. **生の電荷のヤコビアン**: 依頼元で扱う必要はない。scratch ビルドは `src/` を改変したものなので共有しない。GPUMD 側の結果だけを渡す。
4. **日程**: 見通しはない。DES-0005・ADR-0006 の人間の承認と、GPU 時間による。
5. **承認用の資料**: 必要になったら依頼する。

## 4. 参考（DES-0005 草案、未承認）
新モデルは、電荷を q_a = Σ_b φ_ab (h_a − h_b) とする（h_a は既存ネットワークの出力、φ は対称な型ペアの動径関数）。Σq = 0 が構成上厳密に成り立ち、中性化の平均値の差し引きが不要になる。BEC は局所な厳密勾配になる。詳細は `specs/design/DES-0005-qnep-charge-conserving-bec.md`。表現力の確認（段階 5a）で BEC RMSE が 2 倍を超える場合は、停止して人間に報告する。
