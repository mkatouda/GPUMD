# VER-0038: per-atom normalised, shift-stabilised C6 weights in dftd3 (ADR-0008)

- Status: verified 2026-11-18, RTX A6000 (sm_86), CUDA 12.3, `make CUDA_ARCH="-arch=sm_86" -j4`. Type: defect fix, regression, focused tests, timing. Requirements DR-001, DR-003 (AC-3 amended). Spec: `specs/decisions/ADR-0008-dftd3-c6-weight-normalization.md` (Accepted 2026-11-18).
- Change: `src/force/dftd3/dftd3.cu` (`store_cn_weights`, `CnWeights`/`load_cn_weights`, `get_c6_factorized`): the cached per-atom weights are normalised after shifting the squared CN distances by their minimum; `c6 = Z`, `dc6 = dZ`; the `W < 1e-30f` fallback is removed. Same maths as upstream `5c104c42`, evaluated per atom (cache) instead of per pair.
- Binaries: OLD = develop bccda6b6 (md5 238ab537a0fae5f1daed3e6ba2220696), NEW = this change (md5 84a65a1b7c9ffb9f38fe4a867c88a9ee), MASTER = upstream 5c67f365 (worktree `base-master-5c67f365`).
- Reference: simple-dftd3 1.7.0 (`/home/katouda/miniforge3/envs/py312-simpledftd3`), PBE/BJ, cutoffs 12/6, via `tests_pytest/fixtures/dftd3/generate_reference.py::reference`; values in `tests_pytest/fixtures/dftd3/c6_underflow_reference.json` (not altered).

## Defect (before)
Dense H70 and Cu35H35 clusters (VER-0017 structures, `extreme_cn.py`): OLD differs from MASTER by dE -8.11 / -7.25 eV, dF 4.3e-2 / 7.2e-2 eV/A, dV 1.14 / 2.20 eV; the first two equal the errors against simple-dftd3 recorded in UPSTREAM-0001. Compressed H fcc (256 atoms) and Cu fcc (4000 atoms) differ by 1e-5..5e-5 eV; Cu/Na lattice scans (with and without a C interstitial) show no difference above 1e-6 eV/atom.

## Spec impact (DR-003 AC-3)
`test_dftd3_zero.py::test_bj_output_bit_identical_to_pre_change_binary` compared the dump text of five frozen cases with output of the pre-change binary. NEW differs from those stored values by 6e-10..3e-8 relative in energy, <= 5e-8 eV/A in force, <= 5e-7 eV in virial (all-zero NEP; repeats of OLD and of NEW are bit-identical to themselves). Human decision 2026-11-18 (option A): the test now compares numerically with the DR-001 AC-1 caps; the stored values are not regenerated; the explicit-`bj` vs default test stays bit-identical. DR-003 AC-3 carries a dated amendment.

## Limitations / not verified
- CuH70 does not discriminate in AC-2 and AC-3; the discriminating systems are H70 (AC-2, AC-3) and both clusters against simple-dftd3 (AC-1).
- Energy and virial of the clusters with NEP89 are noisy (~5e-4 eV between identical runs); all cap checks use the all-zero NEP.
- `qnep_pppm_future_bec` failure against OLD: attributed to pppm float noise by its absence against MASTER and by the case not using D3; not re-run.
- Zero damping accuracy beyond the existing tests (`test_dftd3_zero.py`), HIP build, replica (no D3 there), multi-element sweeps with very large CN other than the two clusters.
- Bit-level agreement with upstream is not reached or claimed (per-atom vs per-pair evaluation order).
